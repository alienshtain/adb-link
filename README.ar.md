# ADB Link

**تطبيق واحد يربط هاتف أندرويد بحاسوب لينكس في الاتجاهين.**

🖥️ تحكّم بالهاتف من الحاسوب &nbsp;·&nbsp; 📱 تحكّم بالحاسوب من الهاتف &nbsp;·&nbsp; 🔌 USB وWi-Fi وTailscale وبلوتوث

## ⚡ التنصيب بأمر واحد

**💻 الحاسوب** — أي توزيعة (Fedora, Ubuntu, Debian, Arch, openSUSE …):

</div>

```bash
curl -fsSL https://raw.githubusercontent.com/alienshtain/adb-link/main/install.sh | bash
```

<div dir="rtl" align="right">

يثبّت السكربت كل ما يحتاجه التطبيق (adb وGTK 4 وlibadwaita وscrcpy وbrightnessctl وplayerctl وأدوات الحافظة …)، ويضيف **ADB Link** إلى قائمة التطبيقات، ويضع الأمر `adblink` في المسار. يطلب كلمة المرور مرة واحدة.

لتشغيله تلقائياً في الخلفية عند تسجيل الدخول، وتثبيت تطبيق الهاتف في الوقت نفسه:

</div>

```bash
curl -fsSL https://raw.githubusercontent.com/alienshtain/adb-link/main/install.sh | bash -s -- --autostart --phone
```

<div dir="rtl" align="right">

**📱 الهاتف** — أي هاتف أندرويد 8 أو أحدث:

| الطريقة | الخطوات |
|---|---|
| من الحاسوب | وصّل الهاتف بكبل USB (مع تفعيل تصحيح USB) ثم شغّل `adblink install-phone`، أو من تبويب **Link** اضغط *تثبيت* |
| يدوياً | نزّل `adblink.apk` من صفحة [Releases](../../releases) وافتحه على الهاتف |

> اسم المستودع في الأوامر هو `alienshtain/adb-link`. إن أنشأت نسخة (fork) فغيّره، أو استخدم `ADBLINK_REPO=you/adb-link`.

## ✨ ماذا يفعل التطبيق؟

### 🖥️ من الحاسوب (النافذة)

| | |
|---|---|
| 📱 **لوحة الهاتف** | لوحة بشكل هاتف على الجانب: إعدادات سريعة (واي فاي، بلوتوث، وضع الطيران، عدم الإزعاج، كتم الصوت …) وأزرار للسطوع والوسائط ولقطة الشاشة والكاميرا ومرآة الشاشة. **رتّبها كما تشاء**: اضغط القلم، ثم اسحب الأزرار أو استخدم ◀ ▶ أو ✕، وأضف أي زر بـ **+**، ويمكنك إعادة الضبط في أي وقت. |
| 🔔 **الإشعارات** | قائمة إشعارات الهاتف مع الاختصارات السريعة. |
| 📞 **المكالمات** | نافذة منبثقة وإشعار على الحاسوب مع زرّي *الرد* و*الرفض*، وخيار لإيقاف الوسائط مؤقتاً أثناء المكالمة. |
| 👤 **جهات الاتصال** | الاتصال أو إرسال رسالة عبر شريحة SIM. |
| 📦 **التطبيقات** | تثبيت التطبيقات وحذفها وحفظها بصيغة APK (مع أجزائها)، مع البحث والتصفية. |
| 📁 **الملفات** | تصفّح الهاتف، ورفع الملفات **والمجلدات**، والتنزيل، والسحب والإفلات، وإنشاء مجلد، والحذف، و**معاينة الصور والفيديو والنصوص** (بالنقر المزدوج، وأسهم لوحة المفاتيح للتنقل)، مع **صور مصغرة** للصور. |
| ⌨️ **الأوامر** | قسمان: *الأجهزة وإعداد adb* و*على الهاتف*. يمكنك إضافة أوامرك الخاصة وترتيبها وتعديلها، وأمر **كتابة نص** يدعم العربية وسائر اللغات. |
| 🔗 **الهاتف ← ربط تطبيق الهاتف** | صفحة واحدة بقسمين: الهاتف نفسه، والخادم الذي يتصل به تطبيق الهاتف (رمز الاقتران وحالة الميزات وتثبيت الأدوات الناقصة بضغطة واحدة). |
| 🔌 **Connect** | مساعد الاتصال عبر Wi-Fi أو بلوتوث أو USB. |

### 📱 من الهاتف (تطبيق ADB Link)

- تشغيل الأوامر والطرفية (Terminal) على الحاسوب
- لوحة لمس للفأرة ولوحة مفاتيح واختصارات ومفاتيح الوسائط
- تصفّح ملفات الحاسوب ومعاينة الصور والنصوص، ورفع الملفات والمجلدات وتنزيلها
- حافظة وإشعارات مشتركة بين الجهازين
- **لون واحد** لأيقونات الأوامر (دائرية ومملوءة) يمكن تغييره من الإعدادات
- زر «ابحث عن حاسوبي» دون الحاجة إلى كتابة عنوان IP

## 📂 أين تُحفظ الملفات؟

كل ما يحفظه ADB Link على الحاسوب يوضع في **`Documents/ADB Link`**: مجلد *From the phone* (ما يرسله تطبيق الهاتف)، و*Phone files* (ما تنزّله من صفحة الملفات)، و*Screenshots* و*Recordings* و*Apps* (تطبيقات APK المحفوظة). يمكن تغيير المجلد من **الإعدادات ← الملفات المحفوظة**. وعلى الهاتف المسار الافتراضي هو `Documents/ADB Link` أيضاً، ويمكن تغييره (مع مجلد الحاسوب) من إعدادات تطبيق الهاتف.

## 🌍 اللغة

العربية الفصحى (من اليمين إلى اليسار) والإنجليزية، من **الإعدادات ← اللغة** في الحاسوب وفي تطبيق الهاتف.

## 🫧 العمل في الخلفية

إغلاق النافذة لا يوقف ADB Link (المكالمات والحافظة وتطبيق الهاتف تستمر في العمل). وتتيح أيقونة شريط النظام (كما في Discord) فتحه أو إغلاقه. في GNOME تحتاج الأيقونة إلى إضافة *AppIndicator* (مثبتة في Ubuntu، وفي Fedora: `sudo dnf install gnome-shell-extension-appindicator`).

## 🔌 الاتصال بالهاتف (Wi-Fi / بلوتوث)

افتح **Connect** في النافذة؛ فهو ينفّذ الخطوات عنك ويشرح أي خطأ بعبارات واضحة.

| الحالة | الحل |
|---|---|
| الهاتف موصول بـ USB | اضغط **التحويل إلى Wi-Fi** ثم افصل الكبل. |
| أندرويد 11 أو أحدث بدون كبل | من خيارات المطور فعّل **Wireless debugging** ثم اختر *Pair with code*. أدخل العنوان والرمز في Connect ← *اقتران* (يُملأ المنفذ تلقائياً). |
| خارج المنزل | ثبّت [Tailscale](https://tailscale.com) على الجهازين. |
| **بلوتوث** | لا يعمل adb مباشرة عبر البلوتوث. ينضم التطبيق إلى شبكة **مشاركة الإنترنت عبر البلوتوث** من الهاتف، ثم يتصل من خلالها: `adblink bluetooth MAC`. |
| `unauthorized` | افتح قفل الهاتف ووافق على رسالة «السماح بتصحيح USB» مع تحديد *Always allow*. |
| `failed to connect` | اضغط **تشخيص**؛ فهو يفحص الشبكة والمنفذ وadb خطوة بخطوة. |

تُحفظ الأجهزة المعروفة ويُعاد الاتصال بها تلقائياً.

## 🖱️ الفأرة ولوحة المفاتيح من الهاتف

ينشئ التطبيق فأرة ولوحة مفاتيح افتراضيتين عبر `/dev/uinput`، وتعملان على **Wayland وX11**. ويحتاج ذلك إلى إذن لمرة واحدة:

</div>

```bash
adblink setup-input
```

<div dir="rtl" align="right">

(أو **Link ← السماح**). وإن بقي شيء ناقص فسيظهر في الهاتف مربع أحمر يوضح السبب بدقة.

## 🧰 الأوامر

</div>

```text
adblink                     فتح النافذة
adblink --background        تشغيل مخفي (تبقى المكالمات والإشعارات تعمل)
adblink server              تشغيل الخادم فقط دون نافذة
adblink doctor              عرض الأدوات الناقصة
adblink install-deps        تثبيت الأدوات الناقصة
adblink setup-input         السماح بالتحكم بالفأرة ولوحة المفاتيح من الهاتف
adblink connect | pair | wifi | diagnose | bluetooth | install-phone
```

<div dir="rtl" align="right">

الإزالة: `bash ~/.local/share/adblink/uninstall.sh` (أضف `--purge` لحذف الإعدادات أيضاً).

## 🏗️ بناء تطبيق الهاتف بنفسك

يتطلب ذلك Flutter وJava 17:

</div>

```bash
bash phone/setup.sh ~/adblink-app --build
```

<div dir="rtl" align="right">

أو ارفع وسماً (`git tag v3.0 && git push --tags`) فيبني GitHub Actions ملف APK ويرفقه بالإصدار تلقائياً.

## ⚠️ ملاحظات مهمة

- يتطلب **GTK ≥ 4.6 وlibadwaita ≥ 1.1** (Ubuntu 22.04 فما فوق، وFedora 36 فما فوق، وDebian 12 فما فوق).
- يدعم أندرويد فقط (iPhone غير مدعوم).
- يعمل البلوتوث عبر مشاركة الإنترنت وليس عبر نقل adb المباشر.
- تمنح ميزة الطرفية الهاتف صلاحية تنفيذ أوامر على الحاسوب، فعطّلها إذا شاركت رمز الاقتران. ويمكنك إلغاء الاقتران من *Link ← إلغاء اقتران الكل*.
