# ADB Link

**تطبيق واحد يربط جوال الأندرويد بحاسوب لينكس — بالاتجاهين.**

🖥️ تحكم بالجوال من اللابتوب &nbsp;·&nbsp; 📱 تحكم باللابتوب من الجوال &nbsp;·&nbsp; 🔌 USB وWi-Fi وTailscale وبلوتوث

## ⚡ التنصيب بأمر واحد

**💻 اللابتوب** — أي توزيعة (Fedora, Ubuntu, Debian, Arch, openSUSE …):

</div>

```bash
curl -fsSL https://raw.githubusercontent.com/alienshtain/adb-link/main/install.sh | bash
```

<div dir="rtl" align="right">

السكربت ينزّل كل ما يحتاجه التطبيق (adb، GTK 4، libadwaita، scrcpy، brightnessctl، playerctl، أدوات الحافظة ولقطة الشاشة …)، ويضيف **ADB Link** لقائمة التطبيقات، ويضع الأمر `adblink`. يطلب كلمة المرور مرة واحدة.

لتشغيله تلقائياً بالخلفية عند الدخول ولتنصيب تطبيق الجوال بنفس الوقت:

</div>

```bash
curl -fsSL https://raw.githubusercontent.com/alienshtain/adb-link/main/install.sh | bash -s -- --autostart --phone
```

<div dir="rtl" align="right">

**📱 الجوال** — أي جوال أندرويد 8 وأحدث:

| الطريقة | الخطوات |
|---|---|
| من اللابتوب | وصّل الجوال بـ USB (تصحيح USB مفعّل) ← `adblink install-phone` (أو تبويب **Link** ← *Install*) |
| يدوياً | نزّل `adblink.apk` من صفحة [Releases](../../releases) وافتحه على الجوال |

> اسم المستودع في الأوامر هو `alienshtain/adb-link`. إذا سويت fork غيّره، أو استخدم `ADBLINK_REPO=you/adb-link`.

## ✨ شنو يسوي

### 🖥️ من اللابتوب (النافذة)

| | |
|---|---|
| 📱 **لوحة الجوال** | شكل جوال على اليمين: إعدادات سريعة (واي فاي، بلوتوث، وضع الطيران، عدم الإزعاج، كتم …)، أزرار، سطوع، ميديا، لقطة شاشة، كاميرا، مرآة الشاشة. **رتّبها حسب حاجتك**: قلم ← اسحب، ◀ ▶، ✕، **+** لإضافة أي شي، إعادة الضبط. |
| 🔔 **الإشعارات** | قائمة إشعارات الجوال مع الاختصارات. |
| 📞 **المكالمات** | نافذة منبثقة + إشعار على اللابتوب مع *رد* / *رفض*، وخيار إيقاف الميديا عند المكالمة. |
| 👤 **جهات الاتصال** | اتصال أو مراسلة عبر الـ SIM. |
| 📦 **التطبيقات** | تنصيب / حذف / حفظ التطبيقات كـ APK (مع الأجزاء)، بحث وفلترة. |
| 📁 **الملفات** | تصفح الجوال، رفع ملفات **ومجلدات**، تنزيل، سحب وإفلات، مجلد جديد، حذف، و**معاينة الصور والنصوص** (دبل كليك، الأسهم للتنقل). |
| ⌨️ **الأوامر** | أزرار أوامرك الخاصة، ترتيب وإضافة وتعديل، وتظهر بتطبيق الجوال أيضاً. |
| 🔗 **Link** | السيرفر الذي يتصل به تطبيق الجوال، رمز الإقران، ما يعمل وما ينقص، وتنصيب الأدوات الناقصة بضغطة. |
| 🔌 **Connect** | مساعد الاتصال عبر Wi-Fi / بلوتوث / USB. |

### 📱 من الجوال (تطبيق ADB Link)

- تشغيل أوامر وتيرمنال على اللابتوب
- لوحة ماوس وكيبورد واختصارات ومفاتيح ميديا، وعرض شاشة اللابتوب
- تصفح ملفات اللابتوب ومعاينة الصور والنصوص ورفع/تنزيل ملفات ومجلدات
- حافظة وإشعارات مشتركة
- **لون واحد** لأيقونات الأوامر (دائرية ومملوءة) تغيّره من الإعدادات
- زر "ابحث عن حاسوبي" بدون كتابة IP

## 🔌 الاتصال بالجوال (Wi-Fi / بلوتوث)

افتح **Connect** بالنافذة. يسوي الخطوات عنك ويشرح الخطأ بكلام واضح.

| الحالة | الحل |
|---|---|
| الجوال على USB | **Switch to Wi-Fi** — ضغطة وحدة، بعدها اسحب الكيبل. |
| أندرويد 11+ بدون USB | خيارات المطور ← **Wireless debugging** ← *Pair with code*. اكتب العنوان والرمز بـ Connect ← *Pair* (المنفذ يُملأ تلقائياً). |
| خارج البيت | نزّل [Tailscale](https://tailscale.com) على الاثنين. |
| **بلوتوث** | adb ما يشتغل مباشرة عبر البلوتوث. التطبيق ينضم لشبكة **Bluetooth tethering** من الجوال (مشاركة الإنترنت ← بلوتوث) ثم يتصل عبرها: `adblink bluetooth MAC`. |
| `unauthorized` | افتح قفل الجوال ووافق على "السماح بتصحيح USB" (مع *Always allow*). |
| `failed to connect` | اضغط **Diagnose** — يفحص الشبكة والمنفذ وadb خطوة بخطوة. |

الأجهزة المعروفة تُحفظ ويعاد الاتصال بها تلقائياً.

## 🖱️ ماوس وكيبورد من الجوال

يسوي التطبيق ماوس/كيبورد افتراضي عبر `/dev/uinput` — يشتغل على **Wayland وX11**. يحتاج إذن مرة وحدة:

</div>

```bash
adblink setup-input
```

<div dir="rtl" align="right">

(أو **Link ← Allow**). إذا بقي شي ناقص يظهر بالجوال مربع أحمر بالسبب بالضبط.

## 🧰 الأوامر

</div>

```text
adblink                     فتح النافذة
adblink --background        تشغيل مخفي (المكالمات والإشعارات تعمل)
adblink server              السيرفر فقط بدون نافذة
adblink doctor              ما الناقص
adblink install-deps        تنصيب الناقص
adblink setup-input         السماح بماوس/كيبورد الجوال
adblink connect | pair | wifi | diagnose | bluetooth | install-phone
```

<div dir="rtl" align="right">

الحذف: `bash ~/.local/share/adblink/uninstall.sh` (أضف `--purge` لحذف الإعدادات).

## 🏗️ بناء تطبيق الجوال بنفسك

يحتاج Flutter وJava 17:

</div>

```bash
bash phone/setup.sh ~/adblink-app --build
```

<div dir="rtl" align="right">

أو ادفع tag (`git tag v3.0 && git push --tags`) فيبني GitHub Actions ملف APK ويرفقه بالـ release.

## ⚠️ ملاحظات

- يحتاج **GTK ≥ 4.6 وlibadwaita ≥ 1.1** (Ubuntu 22.04+، Fedora 36+، Debian 12+).
- أندرويد فقط (iPhone غير مدعوم).
- البلوتوث عبر الـ tethering وليس نقل adb مباشر.
- التيرمنال يعطي الجوال صلاحية shell على اللابتوب — أطفئه إذا شاركت رمز الإقران، ويمكنك إلغاء الإقران (*Link ← Unpair all*).
